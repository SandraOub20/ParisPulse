# Données historiques

Déposer ici les données historiques brutes au format CSV.

Conserver un sous-dossier par instantané, sans modifier les fichiers récupérés. Documenter les sources, filtres, dates, licences et empreintes dans `data/manifests/`. Vérifier les conventions avant de concaténer archives et flux courant.

Les données générées ou téléchargées sont exclues de Git ; la procédure de récupération et la provenance doivent être fournies à la remise.
