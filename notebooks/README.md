# Notebooks et expérimentations

Les équipes 1 à 4 utilisent ce dossier pour leurs expérimentations :

- **Équipe 1** : explorer les données, tester le parsing et expérimenter le
  preprocessing et le feature engineering.
- **Équipes 2 et 3** : configurer les modèles, charger en entrée les données de
  `data/processed/`, produire des prédictions et, si nécessaire, sauvegarder
  les modèles finaux dans `artifacts/`.
- **Équipe 4** : évaluer et comparer les modèles et méthodes des équipes 2 et 3.

Les notebooks servent aux expérimentations ; le code réutilisable est destiné
à `src/`.
