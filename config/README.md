# Configuration à définir ensemble

Copier `project.example.yaml` vers `project.yaml` après discussion E1–E5. Les champs vides sont à renseigner ; `proposed` ne signifie pas validé par le professeur.

- E1 renseigne l'instantané et la source complémentaire.
- E4 propose coupures temporelles, sites réservés, disponibilité et budget local.
- E2/E3 déclarent les méthodes, versions et budgets de calcul.
- E5 utilise des chemins relatifs et définit le routage et la validité des caches.

Versionner la configuration adoptée et documenter toute modification. Les jetons et secrets éventuels ne vont pas dans ce fichier. Aucun chargeur de configuration n'est encore implémenté.
